# RWY — Brand Portfolio (Next.js)

Brand page for RWY (formerly Double Digit), a Nectar Group brand alongside
HoneyB. Built on the shared brand-portfolio template, cloned from
`../arch-prime-portfolio-next/` (the latest version of the Jinba template).

**First draft, sourced from:** the rebranded landing site
(`../doubledigit-website`, branch `review/rwy-rebrand`; tokens in
`components/dd/dd.css`) and the logo files in `~/Desktop/RWY site assets`.

Hiragino Sans is a system font on Apple devices, so the display face falls
back to Helvetica/Arial elsewhere. Nothing is bundled for it.

```bash
npm install
npm run dev      # http://localhost:4656
```
